
# 📩 Fraud SMS Detector

A simple web app built with Streamlit to classify SMS messages as **Spam** or **Not Spam** using Natural Language Processing and a trained ML model.

## 🚀 Features
- Text preprocessing using NLTK
- TF-IDF vectorization
- Trained classification model
- User-friendly web UI with Streamlit

## 🔧 Technologies Used
- Python
- Streamlit
- scikit-learn
- NLTK
- pickle (for model saving)
